# Regularized Local-Field Inference of Kinetic Ising Models from Finite Nonequilibrium Time Series

Code and data accompanying

> H.-R. Zang, H.-L. Zeng, and E. Aurell, *Regularized Local-Field Inference of Kinetic Ising Models from Finite Nonequilibrium Time Series* (2026).

## Contents

| Path | Description |
|---|---|
| `tables/` | Numerical results (LaTeX tables, as in the Supplemental Material) |
| `data/` | The same results as CSV files (generated by `scripts/tables_to_csv.py`), plus `fig4_coverage.csv` and `fig4_zhist.csv` for Fig. 4(a,b) |
| `scripts/` | Plotting scripts for Figs. 4–6 of the paper and the shared style (`style.py`) |
| `figures/` | Figs. 4–6 as produced by the scripts (PDF for print, PNG for preview) |
| `src/` | **TODO:** simulation and inference code (Glauber dynamics, SUH, SUH+ridge, PANN, PBNN, nMF) |

| Figure | Script | Data |
|---|---|---|
| Fig. 4 — posterior calibration | `make_fig4_calibration.py` | `fig4_coverage.csv`, `fig4_zhist.csv`; panel (c) values (σ̄ and RMSE per regime) are set in the script |
| Fig. 5 — stabilization gain vs ρ | `make_fig5_regime.py` | `S_regime.csv` |
| Fig. 6 — observation noise and coupling asymmetry | `make_fig6_robustness.py` | `S_panelE.csv`, `S_asym.csv` |

### CSV conventions
* `X, X_err`: mean and 95% confidence half-width over independent realizations.
* Paired differences `Delta` are differences of `log10 MSE` relative to the reference estimator,
  with 95% confidence half-widths in the `_err` column.
* `fig4_coverage.csv`: empirical minus nominal coverage of the PBNN credible intervals, in percent,
  at 25 nominal levels, for the four (g, ρ) regimes.
* `fig4_zhist.csv`: normalized histograms (bin width 0.1) of the standardized errors
  z_ij = (Ĵ_ij − J_ij)/σ_ij, 7600 values per regime.

## Reproducing the figures

```bash
pip install numpy matplotlib
make            # regenerates data/*.csv and figures/Fig4-6
```
The figures use bold Liberation Sans (metric-compatible with Arial); matplotlib falls back
to Arial or DejaVu Sans if it is not installed.
